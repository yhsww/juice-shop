# Regra de evidência — Fase 1

A automação pode afirmar somente o que foi executado e observado:
- cenário executado;
- ações tentadas;
- dados fornecidos;
- URL observada;
- texto visível;
- screenshot capturado;
- execução técnica concluída ou inconclusiva.

Se a interface não permitir confirmar um comportamento, o registro deve permanecer inconclusivo ou sem confirmação.

Não preencher automaticamente requisitos não observados, mensagens que não apareceram, dados de negócio não fornecidos, resultados esperados como se fossem observados ou endpoints/processos internos.

A análise funcional e a derivação de requisitos permanecem com o pesquisador.
